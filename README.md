# Bordados Danny

Bordados Danny es un sitio web estático para presentar la información y servicios del proyecto.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- GitHub
- Cloudflare Pages

## Publicación

El sitio se publica mediante GitHub y Cloudflare Pages.

## Estructura principal

- `index.html`: estructura y contenido principal del sitio.
- `styles.css`: estilos visuales y responsive.
- `script.js`: comportamiento interactivo del sitio.
- `assets/`: imágenes y recursos del sitio.
- `AGENTS.md`: instrucciones permanentes de trabajo para Codex y otros agentes.

## Probar localmente

Para probar el sitio en la computadora:

1. Abrir el proyecto en Visual Studio Code.
2. Instalar la extensión Live Server si no está instalada.
3. Abrir `index.html`.
4. Usar la opción "Open with Live Server".

## Publicar cambios

Usar estos comandos desde la raíz del proyecto:

```bash
git add .
git commit -m "Descripción del cambio"
git push
```
